# AGENTS.md — workflow de travail demandé par Nicolas

Ce fichier décrit la procédure à suivre **à chaque évolution demandée**, sans
avoir besoin de la répéter.

## 1. Branche dédiée

Toujours travailler dans une branche dédiée (ex. `feat/<sujet>-80ae23`),
jamais directement sur `main`.

## 2. Tests et documentation

- Réaliser des **tests pour chaque évolution** (pytest dans `tests/`, ex.
  `tests/test_evolutions.py`) et les documenter (docstrings explicites).
- Mettre à jour le `README.md` quand le comportement d'un outil change
  (signature, en-têtes PGN, horloge, bouton web...).
- Ne **pas** committer les notes brutes de la demande (ex. `prompt.txt`).

## 3. Sanitizers (à passer en local avant chaque push)

```bash
source .venv/bin/activate
ruff check .
node --test tests/web/util.test.mjs
npx eslint web/util.js tests/web/util.test.mjs eslint.config.mjs
LICHESS_MCP_STOCKFISH=/chemin/stockfish python -m pytest tests/ -q   # tests d'analyse
```

Notes :
- Les tests d'analyse nécessitent un binaire Stockfish (`LICHESS_MCP_STOCKFISH`
  ou `stockfish` dans le PATH ; en CI il est installé via `apt install stockfish`).
- La CI vérifie aussi que le serveur MCP démarre et expose les outils de base
  (check `fastmcp.Client(...).list_tools()` dans `.github/workflows/ci.yml`).

## 4. Commit

Commit avec le format :

```bash
git commit -m "<message>"

# toujours suivi du trailer :
Generated by Mistral Vibe.
Co-Authored-By: Mistral Vibe <vibe@mistral.ai>
```

## 5. Push, PR, CI, merge

1. Itérer en local jusqu'à ce que **tous les tests passent** et les sanitizers
   soient verts.
2. Pousser la branche (`git push -u origin <branche>`) et ouvrir une **PR** vers
   `main` (titre explicite, description des évolutions + tests effectués).
3. Corriger **tous les problèmes remontés par la CI** jusqu'au vert
   (rellire les check runs du PR).
4. **Merger la PR dans `main`** une fois la CI verte.

## 6. Post-merge (déploiement)

```bash
docker compose down
git checkout main && git pull --ff-only origin main
docker compose up -d --build
# ouvrir Edge sur https://mazurkiewicz1.zapto.org
```

Vérifier que le site répond (HTTPS 200) et faire un smoke test rapide si pertinent.
